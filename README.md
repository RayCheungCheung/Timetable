## [1.01] - 2026-09-11

### ✨ 新增 (Added)

#### 📅 日期搜尋功能
- 搜尋欄而家支援**日期格式**搜尋，可以快速搵到某日嘅假期、備註或課堂。
- 支援多種日期格式：
  - 中文：`6月4`、`6月4日`
  - 點分隔：`6.4`
  - 減號分隔：`6-4`
  - 逗號分隔：`6,4`
  - 斜線分隔：`6/4`
  - 完整日期：`2026-06-04`、`2026/06/04`
  - 英文：`4 th June`、`4th June`、`June 4`
  - 純數字：`604`（6月4）、`1204`（12月4）
- 搜尋結果會顯示：
  - 該日是否為假期（附假期名稱、日期範圍、備註）
  - 該日是否為週末
  - 該日嘅所有課堂
  - 如果冇特別事項，會顯示「沒有特別事項」

#### ⏱️ 午休刷臉倒計時
- 星期一至五午休期間（12:15 ~ 14:10），NOW 卡片會顯示刷臉倒計時：
  - **12:15 ~ 13:30**：顯示「午休」，倒數距離 **13:30 刷臉開始**
  - **13:30 ~ 14:05**：顯示「刷臉中」，倒數距離 **14:05 刷臉結束**
  - **14:05 ~ 14:10**：顯示「午休」，倒數距離 **14:10 上課**
- 星期六唔會顯示刷臉倒計時，正常顯示午休。

#### 🎨 主題切換按鈕重新設計
- 主題切換按鈕移到**右上角**，變成圓形按鈕。
- 深色模式顯示 ☀️，淺色模式顯示 🌙。

#### 📊 考試倒數（已移除）
- 曾經加入考試倒數功能，但因為穩定性問題，已喺 1.01 版本移除。
- 未來版本會重新加入。

### 🔧 修正 (Fixed)

#### 防閃爍更新
- 修正即時倒數頁面「每秒閃一下」嘅問題。
- 而家只會更新倒數數字，唔會重建整個卡片。
- 只有當狀態類型改變（例如由「午休」變成「刷臉中」）時，先會重建卡片。

#### Coming Up 邏輯修正
- 修正 Coming Up 卡片嘅顯示邏輯：
  - **正在上課時**：Coming Up 顯示下一個事件（小休 / 午休）
  - **午休時**：Coming Up 顯示下午第一堂課
  - **小休時**：Coming Up 顯示下一堂課

#### 星期六課表修正
- 修正星期六課表，補回第 2 至第 5 節課。
- 星期六第 2 節為「英文」，老師為「梁婉瑩」。

#### 科目名稱修正
- 「數學」改為「數學(代數)」
- 「數學 幾」改為「數學(幾何)」
- 「分組英文」改為「英文」，老師為「梁婉瑩」
- 「分組資訊科技」老師改為「黃燦霖」
- 「中文」老師統一為「劉梓晴」

#### 卡片展開修正
- 修正課表卡片點擊展開時，高度異常收縮嘅問題。
- 展開後卡片會向下擴展，唔會縮細。
